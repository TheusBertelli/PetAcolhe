# Capturas reais da aplicação

Inclua nesta pasta as capturas realizadas depois de executar o PetAcolhe no Expo Snack ou em um dispositivo/emulador. Não use imagens mockadas como se fossem evidência de execução.

Arquivos solicitados pela atividade:

- `login.png` — tela de Login;
- `home.png` — tela Home após login válido;
- `sobre.png` — tela Sobre com a Toolbar;
- `contato.png` — tela Contato com a Toolbar.

Após adicionar as imagens, vincule-as na seção de capturas do `README.md`.
